## 🚀 วิธีเปิดใช้งาน (How to Run)
1. **เปิดผ่านเบราว์เซอร์โดยตรง:** 
   - ดับเบิลคลิกที่ไฟล์ `index.html` ในโฟลเดอร์ `shopee-automation/`
2. **เปิดผ่าน Local Server (แนะนำ):**
   - รันคำสั่ง `python -m http.server 8080` ที่โฟลเดอร์หลัก
   - เข้าผ่านลิงก์: `http://localhost:8080/shopee-automation/`
3. **หรือดับเบิลคลิกไฟล์ชอร์ตคัต:**
   - ดับเบิลคลิกที่ `run_websites.bat` ในโฟลเดอร์หลัก
